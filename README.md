- Пакеты Python: см. `requirements.txt` в каждой лабе

## Как работать с репозиторием
Каждая лабораторная лежит в отдельной папке (`Lab1/`, `Lab2/`, ...) и содержит:
- исходники C++ (модули `.cppm` + `main.cpp`),
- `CMakeLists.txt` для сборки,
- Python-скрипты для генерации данных и проверки результата,
- собственный `README.md` с инструкцией по запуску.
