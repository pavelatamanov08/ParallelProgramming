# Лабораторная работа №3: Параллельное умножение матриц с использованием MPI

Данный репозиторий содержит решение лабораторной работы по параллельному программированию. Цель работы — модификация последовательной программы умножения матриц для параллельной работы по технологии MPI, проведение серии экспериментов на суперкомпьютере и анализ эффективности распараллеливания.

## 📂 Структура проекта

- 'main.cpp' — точка входа в программу. Управляет запуском последовательной и MPI-версий, замеряет время и проверяет корректность.
- 'matrix.hpp' — класс 'Matrix' для хранения и удобной работы с двумерными массивами.
- 'matrix_io.cpp' / '.hpp' — функции чтения/записи матриц в файл и логирования результатов в 'benchmark.csv'.
- 'matrix_multiply.cpp' / '.hpp' — реализация последовательного ('multiplySequential') и параллельного ('multiplyMPI') алгоритмов умножения.
- 'mpi_utils.cpp' / '.hpp' — обертка над MPI для инициализации и финализации окружения ('MPIEnvironment').
- 'gen.py' — скрипт на Python для генерации случайных матриц заданного размера (использует 'numpy').
- 'plot_perf.py' — скрипт на Python для построения графиков по результатам из 'benchmark.csv'.
- 'CMakeLists.txt' — файл сборки для CMake.
- 'run_all.slurm' — скрипт для автоматического запуска серии экспериментов через систему управления задачами Slurm.
- 'generate_matrices.sh' — Bash-скрипт для генерации матриц всех нужных размеров прямо на кластере.

## 🛠 Требования

- **Компилятор с поддержкой C++11** (Intel 'icpc'/'g++', MSVC).
- **Библиотека MPI** (Intel MPI, OpenMPI, MS-MPI).
- **CMake** версии 3.20 и выше.
- **Python 3** с библиотеками 'numpy', 'pandas', 'matplotlib' (для генерации данных и построения графиков).

## 💻 Сборка и запуск (Локально)

1. Сгенерируйте тестовые матрицы (по умолчанию создаются файлы 'matrix_a.txt' и 'matrix_b.txt' размером 200x200):
   'python gen.py'

2. Соберите проект с помощью CMake:
   'mkdir build && cd build'
   'cmake ..'
   'cmake --build . --config Release'

3. Запустите программу (локально, на 1 процессе):
   './Lab3'

   *Для запуска на нескольких процессах локально используйте 'mpiexec -n 4 ./Lab3'.*

## 🚀 Запуск на суперкомпьютере «Сергей Королёв»

Эксперименты проводились на суперкомпьютере Самарского университета. На кластере используется система управления задачами **Slurm**.

1. Скомпилируйте программу на узле 'login' с помощью Intel MPI:
   'module load intel/icc18'
   'module load intel/mpi4'
   'mpiicpc -std=c++11 -O2 -o Lab3 main.cpp matrix_io.cpp matrix_multiply.cpp mpi_utils.cpp'

2. Сгенерируйте матрицы всех необходимых размеров (200, 400, 800, 1200, 1600, 2000) с помощью Bash-скрипта:
   'chmod +x generate_matrices.sh'
   './generate_matrices.sh'

3. Запустите серию экспериментов (24 комбинации: 6 размеров × 4 варианта количества ядер):
   'sbatch run_all.slurm'

4. После завершения задания (проверка: 'squeue -u $USER') результаты будут записаны в файл **'benchmark.csv'**.

## 📊 Результаты и визуализация

После скачивания файла 'benchmark.csv' на локальный компьютер, запустите скрипт для построения графиков:
'python plot_perf.py'

Скрипт создаст файлы 'performance.png' (общий обзор) и 'classic_speedup.png' (классический график ускорения), которые можно использовать в отчете.

### Ключевые выводы по экспериментам:
- На малых матрицах (200x200) накладные расходы MPI превышают выгоду от параллелизма, ускорение близко к 1.
- На больших матрицах (2000x2000) достигается значительное ускорение (до ~4 раз на 8 ядрах), что демонстрирует эффективность технологии MPI для ресурсоемких задач.
- Накладные расходы на передачу данных ('MPI_Bcast', 'MPI_Scatterv', 'MPI_Gatherv') оказывают существенное влияние на итоговое время работы.
